Datenaustausch mit der Handy-App

Zum Handy: Sicherung herunterladen, die Datei aufs Handy bringen (z. B. per Mail oder Cloud) und in der Handy-App unter Daten → Sicherung importieren einlesen.
Vom Handy: In der Handy-App unter Daten eine Sicherung speichern und hier importieren.
Achtung: Der Import ersetzt alle Daten der Web-App durch die Daten aus der Datei. Der bisherige Stand wird vorher auf dem Server unter database/backups/ gespeichert.
